길 안내 데이터 구조

길 안내 데이터는 각 갈림길에서 사전에 건물 벽에 부착된 실제 이미지를 카메라가 인식하면 사용자 화면에 재생되는 길 안내 애니메이션이다. 각 갈림길에서 재생되는 하나의 애니메이션이 클립이고, 각 클립은 다음 갈림길 또는 최종 목적지까지 도달할 수 있도록 중간점을 안내하는 프레임으로 구성된다.

  • 프레임 구성

    • 프레임은 '순번' 객체, '화살표' 객체, '안내 문구' 객체 등으로 구성되며, 시간 흐름에 따른 프레임의 객체를 표시하기 위하여 재생 시간, 지연 시간을 포함한다. 이외에도, 각 객체의 위치, 방향, 크기 조절 값을 설정하여 원하는 각 객체의 배치를 조절할 수 있다.
