템플릿 기반 길 안내 생성

  1. 가이드 이름 설정

    2. '가이드 명' 필드에 원하는 이름을 입력합니다. 사용자가 키워드로 검색하여 찾을 수 있도록 조직 이름과 생성 날짜를 조합하여 이름을 지정합니다. 예) mirae 26-10-21

  2. 템플릿의 클립 수와 클립 당 프레임 수 설정

    3. '클립 수' 필드에 원하는 클립 수를 입력합니다. '프레임 수' 필드에 원하는 클립 당 프레임 수를 입력합니다. 예) 3개의 클립과 각 클립 당 5개의 프레임을 생성하려면 '클립 수'에 3, '프레임 수'에 5를 입력합니다. 길 안내 데이터의 구성은 여기를 클릭하여 참고하세요.

  3. 템플릿 기반 길 안내 생성

    4. '템플릿 생성' 버튼을 클릭하면 템플릿 기반 길 안내가 생성됩니다.

  4. 생성된 길 안내 미리 보기

    5. '미리 보기' 버튼을 클릭하면 생성된 길 안내 애니메이션을 미리 볼 수 있습니다.
