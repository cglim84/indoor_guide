생성된 길 안내 데이터를 로컬 파일 시스템으로부터 읽고 저장할 수 있다. 원격 서버에 저장된 길 안내 데이터를 읽고 저장할 수 있다.

  1. 로컬 시스템으로부터 길 안내 데이터 읽기

    2. 편집기 화면의 (4) '가이드 관리' 패널에서 좌상단의 '파일 선택' 버튼을 클릭하고 로컬 파일 시스템으로부터 길 안내 데이터 파일을 선택한다. 길 안내 데이터 파일(.json)과 함께 평면도 이미지 파일, 타겟 이미지 파일도 선택한다. '가이드 파일 읽기(로컬)' 버튼을 클릭하면 선택한 길 안내 데이터 파일을 읽어 'JSON 코드 수정' 패널에 표시한다.

  2. 로컬 시스템에 길 안내 데이터 저장

    3. 편집기 화면의 (4) '가이드 관리' 패널에서 '가이드 파일 저장(로컬)' 버튼을 클릭하여 편집된 길 안내 데이터를 로컬 파일 시스템에 저장한다. 버튼 왼쪽에 가이드 이름을 입력하면 해당 이름에 확장자(.json)가 붙혀진 이름으로 저장된다.

  3. 원격 서버로부터 길 안내 데이터 읽기

    4. 편집기 화면의 (4) '가이드 관리' 패널에서 '원격 가이드 읽기' 버튼의 왼쪽 입력 필드에 가이드 이름을 입력하고 버튼을 클릭하면 원격 서버에 저장된 길 안내 데이터 파일을 읽어 'JSON 코드 수정' 패널에 표시한다. 원격 서버에 저장된 평면도 이미지 파일과 타겟 이미지 파일도 함께 다운로드한다. (1) '가이드 생성' 패널의 '미리 보기' 버튼을 클릭하면 해당 길 안내 데이터의 애니메이션을 확인할 수 있다.

  4. 원격 서버에 길 안내 데이터 저장

    5. 편집기 화면의 (4) '가이드 관리' 패널에서 '가이드 원격 저장' 버튼의 왼쪽에 위치한 '파일 선택' 버튼을 클릭하여 길 안내 데이터와 함께 저장할 이미지 파일들을 선택한다. 그 왼쪽에 위치한 입력 필드에 원격 서버에 저장할 길 안내 이름을 입력한다. '가이드 원격 저장' 버튼을 클릭하여 길 안내 데이터를 원격 서버에 저장한다.
