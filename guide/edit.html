템플릿 기반으로 생성된 길 안내를 편집할 수 있다. 가이드 데이터 구조와 편집기 화면을 참고한다.

  1. 이미지 파일 설정

    2. 편집기 화면의 (4) '가이드 관리' 패널에서 '파일 선택' 버튼을 클릭하고 평면도 이미지로 사용할 이미지 파일을 선택하여 미리 보기 실행 시 배경 이미지로 표시한다.

  2. 클립 추가/삭제

    3. 편집기 화면의 (2) 'JSON 코드 수정' 패널에서 클립 개수를 확인하고 복사와 붙혀넣기를 수행하여 클립을 추가하고, 불필요한 클립은 삭제한다.

    'targetImage' 키에 대한 값으로 이미지 타겟으로 사용할 이미지 파일을 지정하고 'backgroundImage' 키에 대한 값으로 평면도 이미지로 사용할 이미지 파일을 지정한다.

  3. 프레임 추가/삭제

    4. 각 클립의 프레임 개수를 확인하고 복사와 붙혀넣기를 수행하여 프레임을 추가하고, 불필요한 프레임은 삭제한다.

  4. 프레임 객체 변경

    5. 각 프레임은 '순번' 객체, '화살표' 객체, '안내 문구' 객체 등으로 구성된다. '순번' 객체는 'number' 키의 값으로 프레임의 순번에 해당하는 숫자 아이콘을 지정한다. (예) 1번의 경우, "number": "counter_1"

    '화살표' 객체는 'icon' 키의 값으로 가이드 데이터 구조에서 설명한 아이콘을 지정한다. (예) 전진 방향 화살표의 경우, "icon": "arrow_forward"

    '안내 문구' 객체는 'text' 키의 값으로 안내 문구를 지정한다. (예) "text": "앞으로 10m 가세요."

  5. 프레임 객체 배치

    6. '미리 보기' 버튼을 클릭하여 각 객체의 배치를 확인하며 배치를 조정할 수 있다. 템플릿 기반으로 생성된 길 안내 애니메이션에 사용되는 객체의 기본 위치는 평면도 이미지의 좌상단이다. 평면도 이미지의 좌표계는 좌상단이 원점이고, 오른쪽이 x축 양의 방향이고 아래쪽이 y축 양의 방향임을 고려하여 순번 아이콘 객체, 방향 아이콘 객체, 안내 글 객체의 위치를 조정한다.

    순번 아이콘 객체, 방향 아이콘 객체, 안내 글 객체의 위치는 "numberPosition", "iconPosition", "textPosition"의 키를 가지며 값으로 2차원 좌표 값을 지정한다. (예) "numberPosition": {"x": 100, "y": 200}

    원하는 크기로 조정할 수 있다. (예) 1.5배 확대하는 경우, "numberScale": 1.5

    방향을 조정하는 경우, 회전은 시계 방향으로의 회전이 양의 각도 값을 갖는다. (예) 45도 회전하는 경우, "iconRotation": 45

  6. 프레임 재생 시간과 지연 시간 설정

    7. 재생 시간과 지연 시간의 키는 "duration"과 "delay"이며, 값으로 초 단위의 시간을 지정한다. (예) 1.5초 재생하는 경우, "duration": 1.5 (예) 1초 지연하는 경우, "delay": 1.0
