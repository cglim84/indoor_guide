템플릿을 기반으로 길 안내 데이터를 생성할 수 있다. 가이드 데이터 구조와 편집기 화면을 참고한다.

  1. 가이드 이름 설정

    2. 편집기 화면 (1) '가이드 생성' 패널의 '가이드 명' 필드에 원하는 이름을 입력한다. 사용자가 키워드로 검색하여 찾을 수 있도록 조직 이름과 생성 날짜를 조합하여 이름을 지정하는 것을 권장한다. 파일 이름으로 사용되니 영어 이름을 권장한다. (예) mirae 26-10-21

  2. 템플릿의 클립 수와 클립 당 프레임 수 설정

    3. '클립 수' 필드에 원하는 클립의 개수를 입력한다. '프레임 수' 필드에 원하는 클립 당 프레임의 개수를 입력한다. (예) 3개의 클립과 각 클립 당 5개의 프레임을 생성하려면 '클립 수'에 3, '프레임 수'에 5를 입력한다. 이 경우, 3개의 클립이 각각 5개의 프레임으로 구성되며, 편집 과정에서 프레임을 추가하거나 삭제할 수 있다.

  3. 템플릿 기반 길 안내 생성

    4. '템플릿 생성' 버튼을 클릭하면 템플릿 기반 길 안내가 생성된다.

  4. 생성된 길 안내 미리 보기

    5. '미리 보기' 버튼을 클릭하면 생성된 길 안내 애니메이션을 미리 볼 수 있다.

  5. 길 안내 데이터 초기화

    6. 생성된 길 안내를 초기화하려면 '새 가이드' 버튼을 클릭하고 '가이드 이름 설정'부터 다시 시작한다.
